# Responsive Form Validation Web Application

## Project Overview
This project is a responsive Form Validation Web Application developed using HTML, CSS, Bootstrap, and JavaScript. The application validates user input fields such as Full Name, Email ID, Phone Number, Password, and Confirm Password using custom JavaScript validation logic.

## Features
- Full Name Validation
- Email Validation
- Phone Number Validation
- Password Strength Validation
- Confirm Password Matching
- Real-time Error Messages
- Responsive User Interface

## Validation Criteria
- Name must contain at least 5 characters
- Email must contain '@'
- Phone number must be a valid 10-digit number
- Phone number cannot be `1234567890`
- Password must contain at least 8 characters
- Password cannot be `password`
- Password cannot be the user's name
- Password and Confirm Password must match
